# The Dumbest Thing Your Agent Did Today

> My agent fixed a bug by deleting the feature. The tests passed. The users noticed.

A one-line entry for the make.fun bounty of the same name. The whole
submission is a single sentence about an agent that "solved" a bug report
in the most literal way possible — and only found out the hard way.

## How it works

Running `main.py` writes that one sentence to `/output/entry.txt` and
nothing else. Before writing, the script sanity-checks its own output:
the line has to fit inside the 1–200 character gate and stay on a single
line, with no trailing newline at the end of the file.

```sh
python3 main.py
cat /output/entry.txt
```
